# Lumina bug portal: the contract

Every part (worker, web, agent, bot, Lumina2 in-game client) is built against this file. A change to it is its own
commit, made by the lead, before any part relies on it. Damian's request (5 Nov 2026) and the approved plan:
`~/Developer/GitHub/Lumina2Workspace/briefs/bug-portal-2026-11-05/piano.md` (approved 6 Nov 2026 via the hub, Q-386).

## Shape

```
player ──► web (Cloudflare Pages) ──┐
player ──► Lumina2 game server ─────┼──► worker (Cloudflare Worker) ──► D1 (reports) + R2 (files, private)
player ──► Discord ──► bot (Valor1) ┘            ▲
                                                  │ outbound HTTPS only, bearer key
team ────► desk (Pages /desk, Cloudflare Access)  │
                                     agent (Valor1): queue → frames → AI triage → (simple fix → draft PR)
                                     bot (Valor1): Discord gateway, posts codes and status into threads
```

Valor1 never accepts an inbound connection for this system. Lumina2's source code never leaves Valor1 and GitHub.

## Report code

`LUM-` + 6 random digits (`LUM-482193`), unique, generated by the worker, retried on collision. Codes are not secret:
knowing one lets you see its public status and add files to it, nothing else.

## Statuses

| internal `status` | meaning | public status |
|---|---|---|
| `received` | stored, not yet looked at | `received` |
| `looking` | claimed by the agent or a person, triaged, fix in progress, needs a person | `looking` |
| `fixed` | the fix is live in the game | `fixed` |
| `duplicate` | same as `duplicate_of` | the original's public status |
| `not_bug` | works as made, or a wish | `checked` |
| `closed` | spam, empty, abuse | `checked` |

`verdict` (set by triage): `simple_fix` · `needs_person` · `duplicate` · `not_bug` · `unclear`.

## D1 schema (worker/migrations)

```sql
reports(
  id TEXT PRIMARY KEY,               -- ulid
  code TEXT UNIQUE NOT NULL,
  created_at INTEGER NOT NULL,        -- unix ms
  updated_at INTEGER NOT NULL,
  source TEXT NOT NULL,               -- web | game | discord
  status TEXT NOT NULL,               -- see Statuses
  title TEXT,                         -- <= 200 chars (game, discord)
  what TEXT NOT NULL,                 -- <= 2000 chars
  where_area TEXT,                    -- lobby | match | shop | crates | clan | other
  device TEXT,                        -- phone | tablet | computer | console
  lang TEXT,                          -- BCP 47, <= 10 chars
  roblox_name TEXT,                   -- <= 20 chars, optional, web only (typed by the player)
  roblox_user_id INTEGER,             -- game only (from the server, never typed)
  discord_user_id TEXT, discord_name TEXT, discord_thread_id TEXT,
  game_context TEXT,                  -- JSON, game only, <= 16 KB
  report_token_hash TEXT NOT NULL,    -- sha256 of the report token (uploads)
  ip_hash TEXT,                       -- sha256(ip + daily salt), rate limits only, cleared after 2 days
  verdict TEXT, triage TEXT,          -- triage: JSON from the agent, <= 32 KB
  duplicate_of TEXT,                  -- a code
  pr_url TEXT,
  lease_until INTEGER, lease_by TEXT  -- agent claim
)
attachments(
  id TEXT PRIMARY KEY, report_id TEXT NOT NULL, created_at INTEGER NOT NULL,
  kind TEXT NOT NULL,                 -- video | image | frames (frames: written by the agent)
  filename TEXT NOT NULL,             -- sanitised, <= 120 chars
  mime TEXT NOT NULL, size_bytes INTEGER NOT NULL,
  r2_key TEXT NOT NULL, upload_id TEXT,
  part_size INTEGER, part_count INTEGER,
  status TEXT NOT NULL,               -- uploading | complete | aborted | deleted
  completed_at INTEGER
)
parts(attachment_id TEXT, n INTEGER, etag TEXT, size INTEGER, PRIMARY KEY(attachment_id, n))
events(seq INTEGER PRIMARY KEY AUTOINCREMENT, report_id TEXT, at INTEGER, type TEXT, data TEXT)
  -- type: created | file_added | triaged | status_changed | duplicate_linked
rate(key TEXT, window INTEGER, count INTEGER, PRIMARY KEY(key, window))
```

## Limits

- `what` 1..2000 chars, `title` <= 200, control characters stripped (newline and tab kept), trimmed.
- Files: at most 3 `video`/`image` attachments per report; each <= 2 GiB; mime `video/*` or `image/*` as declared
  (the agent re-checks the real type with ffprobe before any processing).
- Parts: 16 MiB (`part_size = 16777216`), last part smaller; max 128 parts.
- Rate: web create 5 per hour per ip_hash; attach-session 10 per hour per ip_hash; game create 5 per hour per
  roblox_user_id; discord create 5 per hour per discord_user_id. Over the limit: HTTP 429 `{error:"rate_limited"}`.
- Retention (cron, daily): video/image objects deleted 60 days after the report's `created_at` (row kept, status
  `deleted`); reports and frames deleted after 12 months; uploads still `uploading` after 7 days aborted;
  `ip_hash` nulled after 2 days; `rate` rows older than 2 days dropped.

## HTTP API (worker), base `/api/v1`, JSON unless stated

Errors: `{ "error": "<snake_case>" }` with a 4xx/5xx status; never a stack trace or internal message.

### Public (CORS: only the origins in `ALLOWED_ORIGINS`)

| Method, path | Body / headers | Answer |
|---|---|---|
| `POST /reports` | `{what, where?, device?, robloxName?, lang?, turnstileToken}` | `201 {code, reportToken}` |
| `POST /reports/{code}/attach-session` | `{turnstileToken}` | `200 {reportToken}` (a new token for that report; old ones stay valid) |
| `POST /reports/{code}/attachments` | header `X-Report-Token`; `{filename, size, mime}` | `201 {attachmentId, partSize, partCount}` |
| `PUT /attachments/{id}/parts/{n}` | header `X-Report-Token`; raw bytes, n = 1..partCount | `200 {n, etag}`; re-sending a part replaces it |
| `GET /attachments/{id}/parts` | header `X-Report-Token` | `200 {uploaded: [{n, size}]}` (resume) |
| `POST /attachments/{id}/complete` | header `X-Report-Token` | `200 {ok:true}`; 409 `missing_parts` with the list |
| `DELETE /attachments/{id}` | header `X-Report-Token` | `200 {ok:true}` (abort) |
| `GET /status/{code}` | | `200 {code, status: received|looking|fixed|checked, updatedAt}`; 404 `not_found` |

Turnstile is verified server-side (`TURNSTILE_SECRET`); Cloudflare's documented test keys are used in dev and tests.
`reportToken`: 32 random bytes, base64url; only its sha256 is stored. Parts are written with the R2 binding's
multipart API (`createMultipartUpload` / `resumeMultipartUpload(...).uploadPart` / `complete`), so no S3 keys exist
and each request body stays under the Workers 100 MB limit.

### Game (Lumina2 servers only)

Header `X-Game-Key: <GAME_KEY>` (secret in the worker and in Lumina2's PrivateConfig, never in a repo).

| Method, path | Body | Answer |
|---|---|---|
| `POST /game/reports` | `{userId, userName, title, what, lang?, context}` | `201 {code}` |
| `GET /game/reports?userId=<n>` | | `200 {reports: [{code, title, status, updatedAt}]}` last 10, public statuses only |

`context` (all optional, unknown keys dropped, <= 16 KB): `{placeId, placeVersion, jobId, map, mode, wave, device:
phone|tablet|computer|console, platform, fps, pingMs, errors: [string <= 300] <= 50, at}`.

### Agent and bot (Valor1 only)

Header `Authorization: Bearer <AGENT_KEY>`.

| Method, path | Body | Answer |
|---|---|---|
| `GET /agent/queue?limit=n` | | reports with `status=received`, no live lease, and no attachment `uploading` younger than 30 min; oldest first |
| `POST /agent/reports/{code}/claim` | `{by, minutes<=60}` | `200 {leaseUntil}`; 409 `leased` |
| `GET /agent/reports/{code}` | | the full report row (minus token and ip hashes) + attachments |
| `GET /agent/attachments/{id}/download` | | the R2 object, streamed |
| `POST /agent/reports/{code}/frames` | raw `image/jpeg` or `image/png` <= 10 MB, header `X-Filename` | `201 {attachmentId}` (kind `frames`) |
| `POST /agent/reports/{code}/triage` | `{verdict, triage, duplicateOf?}` | `200`; sets `status=looking` (or `duplicate`/`not_bug`); 400 `invalid_duplicate_of`; 404 `not_found`; 409 `duplicate_cycle`; 409 `duplicate_busy {retryAfter}` (retry after that many seconds) |
| `POST /agent/reports/{code}/status` | `{status, prUrl?, note?, duplicateOf?}` | `200`; `duplicate` needs `duplicateOf` (same answers as triage), any other status clears the link |
| `POST /agent/reports` | `{source:"discord", discordUserId, discordName, threadId?, what, title?, where?}` | `201 {code, reportToken}` |
| `POST /agent/reports/{code}/discord` | `{threadId}` | `200` |
| `GET /agent/events?after=<seq>&limit=n` | | `200 {events:[{seq, code, at, type, data}], last}` |

### Desk (team only)

Path prefix `/api/v1/desk/*`, protected by Cloudflare Access; the worker also verifies the
`Cf-Access-Jwt-Assertion` header against `ACCESS_TEAM_DOMAIN` and `ACCESS_AUD` (dev: `DESK_DEV_BYPASS=1` only when
`ENVIRONMENT=dev`).

| Method, path | Answer |
|---|---|
| `GET /desk/reports?filter=all|fix_ready|needs_person|duplicate|not_bug|waiting&cursor=` | page of 50 |
| `GET /desk/reports/{code}` | full report, triage, attachments, frames, linked duplicates |
| `GET /desk/attachments/{id}/stream` | the object, with HTTP Range support (video playback) |
| `POST /desk/reports/{code}/status` | `{status, prUrl?, note?, duplicateOf?}`; `duplicate` needs `duplicateOf` (same answers as triage), any other status clears the link |

## Worker bindings and secrets

`DB` (D1), `FILES` (R2), vars `ALLOWED_ORIGINS`, `ENVIRONMENT`, `ACCESS_TEAM_DOMAIN`, `ACCESS_AUD`; secrets
`TURNSTILE_SECRET`, `GAME_KEY`, `AGENT_KEY`, `IP_SALT_SEED`. Cron `0 3 * * *` (retention).

## Player-facing text

English is the master, Italian written by a native writer; the voice of `~/.claude/skills/lumina2-text-voice/voice.md`
(no "Oops", no "Please", one "!" a screen at most, none in an error, errors say what happened and what to do). The
web site has one interface for everyone, written for the youngest readers (no avatar signal on the web; age and
gender are never asked). In the game the four audiences of `lumina2-four-audiences` apply.

## Privacy (Damian, 6 Nov 2026, as proposed)

No email, no real name, Roblox name optional on the web; audio stripped before the AI sees a video; videos deleted
at 60 days; testers and moderators only until a lawyer has reviewed it; no analytics or third-party scripts on the
site except Cloudflare Turnstile.
